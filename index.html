How category counts work

  1. Select one of your books or Chaos Mode, then edit your categories and role lists.
  2. Set each category's minimum and maximum.
  3. Set both numbers equal to require an exact quantity.
  4. When there's room between minimum and maximum, extra slots are randomly assigned among eligible categories.

Each role defaults to one copy; increase “Copies” if duplicates are allowed. Your setup and most recent draw are stored on this device where browser storage is available. Roles with the same title in different books remain separate, and each book can be renamed or replaced through the Book library.
